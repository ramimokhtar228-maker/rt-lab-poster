# معامل RT للتحاليل الطبية | استوديو وبوسترات عرض اليوم الواحد (خصم 70%)
### RT Medical Laboratories - Flash Deal Poster Studio & Progressive Web App (PWA)

تطبيق ويب تقدمي (PWA) متكامل مصمم خصيصاً لحملة **"عرض اليوم الواحد - خصم 70% على جميع التحاليل الطبية"** التابعة لمعامل RT للتحاليل الطبية (RT Medical Laboratories).

---

## 🌟 المميزات الرئيسية (Key Features)

1. **بوسترات إعلانية رسمية عالية الدقة (HD Posters):**
   - **بوستر مربع (1:1 - 1080×1080):** مخصص لمنشورات فيسبوك، إنستغرام، وواتساب.
   - **بوستر رأسي (9:16 - 1080×1920):** مخصص لقصص Instagram Stories، تيك توك، وحالات واتساب، ورول أب العيادات.
   - **بانر عريض (16:9 - 1920×1080):** مخصص لأغلفة فيسبوك، وبانرات المواقع، والشاشات الرقمية.
   - تنزيل فوري عالي الدقة (HD Download) ومعاينة وتكبير (Lightbox Zoom).

2. **استوديو التخصيص والمونتاج الفوري (Live Poster Canvas Studio):**
   - إمكانية تعديل اسم الفرع، أرقام الواتساب، والخط الساخن.
   - تصدير البوستر المخصص مباشرة بصيغة PNG أو JPG بدقة فائقة.

3. **حاسبة الأسعار وقائمة الفحوصات بخصم 70%:**
   - فحص شامل، CBC، سكر تراكمي HbA1c، فيتامين د، وظائف كبد وكلى، دهون ثلاثية.
   - حساب فوري لمقدار التوفير بالجنيه.

4. **تطبيق هاتف محمول معتمد (Progressive Web App - PWA):**
   - يدعم التثبيت المباشر على شاشة الهاتف (Android و iPhone).
   - يعمل بشاشة كاملة وبدون شريط المتصفح، مع دعم وضع عدم الاتصال (Offline).

5. **خدمة سحب العينات مجاناً من المنزل (Home Visit Booking):**
   - نموذج حجز فوري يرسل التفاصيل مباشرة إلى واتساب خدمة العملاء.

---

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19, TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **PWA:** Vite PWA Plugin (`vite-plugin-pwa`) مع Service Worker و Web App Manifest
- **Canvas:** HTML5 2D Canvas للرسم والتصدير عالي الدقة
- **Bundler:** Vite 6

---

## 🚀 تشغيل المشروع محلياً (Run Locally)

1. تثبيت الحزم:
```bash
npm install
```

2. تشغيل خادم التطوير:
```bash
npm run dev
```

3. بناء النسخة الإنتاجية:
```bash
npm run build
```
